# Identifikation von Kunden

die Identifikation der Kunden basiert auf den nationalen Geldwaschereivorschriften. Diese sind nicht in allen Landern gleich gut entwickelt. Schweizer Banken sind verpflichtet, die wirtschaftlich Berechtigten von Firmen und Strukturen zu identifizieren. - See more at: <http://www.swissbanking.org/home/dossiers-link/aia.htm#aia_questions>
