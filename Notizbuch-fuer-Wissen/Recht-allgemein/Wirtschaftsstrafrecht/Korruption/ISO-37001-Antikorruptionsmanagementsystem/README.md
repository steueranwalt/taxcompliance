# ISO 37001 Antikorruptionsmanagementsystem

Mit der neuen Norm ISO 37001 verfugen Sie uber eine Hilfestellung beim Gestalten eines wirksamen Antikorruptionsmanagementsystems. Indem Organisationen die Anforderung der Norm umsetzen, reduzieren sie das Risiko individuelles und institutionelles Fehlverhalten.

  


Um den Anforderungen der Norm gerecht zu werden, mussen Organisationen eine Reihe von Maßnahmen treffen, die sich folgendermaßen zusammenfassen lassen:

  


  * Legen Sie eine Antibestechungspolitik und Richtlinien fest. Die Definition von Bestechung unterliegt den lokalen gesetzlichen Bestimmungen.
  * Kommunizieren Sie die Politik und Richtlinien mit allen Stakeholdern, angefangen von den eigenen Mitarbeitern zu den Lieferanten, Gesellschaftern, Investoren, Beratern, usw.
  * Benennen Sie einen Compliance Manager, der das Anti-Korruptionsprogramm betreut
  * Schulen Sie Ihre Mitarbeiter in Bezug auf Anti-Korruption
  * Fuhren Sie eine Risikobewertung durch, um die relevante Risiken und das Korruptionspotential zu ermitteln
  * Treffen Sie angemessene und verhaltnismaßige Maßnahmen, um sicherzustellen, dass Geschaftspartner und Organisationen innerhalb Ihres Einflussbereichs wirksame Anti-Korruptionskontrollen eingefuhrt haben.
  * Fuhren Sie angemessene Kontrollmechanismen ein, um sicherzustellen, dass Ihre Mitarbeiter die Anti-Korruptionsrichtlinien befolgen, beispielsweise in dem Umgang mit Geschenken und Einladungen
  * Fuhren Sie die Moglichkeit ein, eventuelle Verstoße zu melden und Bedenken zu außern. Der Schutz von Hinweisgebern gehort ebenfalls dazu.
