# Beweis durch Strafurteile

Einwendungen der am finanzgerichtlichen Verfahren Beteiligten gegen die Verwendung strafgerichtlicher Feststellungen und entsprechende Beweisantrage mussen substantiiert werden. Dazu genugt summarisches Bestreiten nicht. Beruhen die strafgerichtlichen Feststellungen auf Gestandnissen eines Mitangeklagten, so bedarf es zur Substantiierung einer annehmbaren Erklarung, warum zu erwarten sei, daß dieser seine Aussagen andern werde (BFHE 153, 393; 124, 305,).
