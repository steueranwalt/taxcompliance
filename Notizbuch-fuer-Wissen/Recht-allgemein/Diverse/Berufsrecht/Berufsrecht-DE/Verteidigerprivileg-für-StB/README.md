# Verteidigerprivileg für StB?

Befugnis der StB, WP zur Strafverteidigung, soweit FA das Strafverfahren selbstandig durchfuhrt ([§ 392 Abs. 1, 1. Hs. AO](<https://www.gesetze-im-internet.de/ao_1977/__392.html>))

  


FA fuhrt das Strafverfahren selbstandig ([§ 386](<https://www.gesetze-im-internet.de/ao_1977/__386.html>) Abs. 2 AO), wenn die Tat 

  1. ausschließlich eine Steuerstraftat darstellt oder
  2. zugleich andere Strafgesetze verletzt und deren Verletzung Kirchensteuern oder andere offentlich-rechtliche Abgaben betrifft, die an Besteuerungsgrundlagen, Steuermessbetrage oder Steuerbetrage anknupfen,
  3. solange gegen einen Beschuldigten wegen der Tat ein Haftbefehl oder ein Unterbringungsbefehl erlassen ist (§ 386 Abs. 3 AO), oder
  4. die StA die Sache an sich zieht oder das FA die Sache an die StA abgibt (§ 386 Abs. 4 AO)
