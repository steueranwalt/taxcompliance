Der Steuerrechner ist ein Hilfsmittel für die provisorische Berechnung des 
geschuldeten Steuerbetrags. Die berechneten Werte sind nicht rechtsverbindlich. In 
einzelnen Gemeinden können allenfalls abweichende Steuerfüsse zur Anwendung 
kommen. Für die Steuerzahlung ist einzig der Betrag auf der Steuerrechnung 
massgebend. 
Die Übermittlung der Daten erfolgt verschlüsselt und die Daten werden unmittelbar 
nach der Berechnung wieder gelöscht. Die Daten werden für keine weiteren 
Auswertungen verwendet.
