# Schweizer Steuerrecht

Rechtstexte, Kreisschreiben und Arbeitsmaterialien zum Schweizer Steuerrecht (Bundes- und kantonale Ebene).

## Unterverzeichnisse

| Verzeichnis | Rechtsgebiet |
|---|---|
| [`DBG/`](DBG/) | Bundesgesetz über die direkte Bundessteuer |
| [`StHG/`](StHG/) | Steuerharmonisierungsgesetz |
| [`MWSTG/`](MWSTG/) | Mehrwertsteuergesetz |
| [`VStG/`](VStG/) | Verrechnungssteuergesetz |
| [`StG/`](StG/) | Bundesgesetz über die Stempelabgaben |
| [`Kantone/`](Kantone/) | Kantonale Steuergesetze (nach Kanton) |
| [`Sonstiges/`](Sonstiges/) | ESTV-Kreisschreiben, Bundesgerichtsentscheide, weitere |

## Dokumenttypen

- **Gesetzestexte** – amtliche Fassungen (SR-Nummer)
- **Kreisschreiben** – Verwaltungsanweisungen der ESTV
- **Bundesgerichtsentscheide** – BGE und unveröffentlichte BG-Urteile
- **Kantonsblätter** – Überblick je Kanton
- **Arbeitshilfen** – interne Materialien
