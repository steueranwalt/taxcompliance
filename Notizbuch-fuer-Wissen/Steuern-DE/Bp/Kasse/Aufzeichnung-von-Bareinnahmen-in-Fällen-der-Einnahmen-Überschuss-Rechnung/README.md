# Aufzeichnung von Bareinnahmen in Fällen der Einnahmen-Überschuss-Rechnung

Das Niedersachsische FG hat im Urteil vom 8.12.2011 (12 K 389/09, EFG 2013, 291, unter I.2.h, m.w.N.; Nichtzulassungsbeschwerde als unzulassig verworfen durch Senatsbeschluss vom 13.3.2013 X B 16/12, BFH/NV 2013, 902) die folgenden drei Moglichkeiten fur eine ordnungsmaßige Aufzeichnung von Bareinnahmen in Fallen der Einnahmen-Überschuss-Rechnung bei Sachverhalten, in denen die Fuhrung von Einzelaufzeichnungen nach den von der hochstrichterlichen Rechtsprechung aufgestellten Grundsatzen nicht ohnehin als zwingend anzusehen ist, aufgezeigt: |   
  
---|---  
  
  * eine geordnete Belegablage mit Einzelaufzeichnungen der Erlose;
  * Verzicht sowohl auf Einzelaufzeichnungen als auch auf ein tagliches Auszahlen des Kassenbestands, aber Aufbewahrung der Ursprungsaufzeichnungen und Abgleich von Soll- und Ist-Bestand der Kasse "in gewissen Abstanden" (insbesondere bei der Nutzung von Registrierkassen);
  * Verzicht sowohl auf Einzelaufzeichnungen als auch auf die Aufbewahrung von Ursprungsbelegen, aber tagliches tatsachliches Auszahlen der Kasse, das in fortlaufenden Kassenberichten dokumentiert wird;
  * demgegenuber genuge das bloße Aufschreiben des taglichen (Gesamt-)Umsatzes ohne Aufbewahrung weiterer Belege den Anforderungen nicht.
