# Verfahrensdokumentation 

BMF-Schreiben vom 14.11.2014. 

  


Rz. 151: Unternehmer mussen fur jedes DV-System eine ubersichtlich gegliederte Verfahrensdokumentation fuhren. Diese Verfahrensdokumentation muss verstandlich und damit fur einen sachverstandigen Dritten in angemessener Zeit nachprufbar sein.

  


Rz. 153: Die Nachvollziehbarkeit muss sich aus der Verfahrensdokumentation ergeben.

  


Rz 155: Beeintrachtigt eine fehlende oder ungenugende Verfahrensdokumentation die Nachvollziehbarkeit und Nachprufbarkeit nicht, liegt kein formeller Mangel mit sachlichem Gewicht vor, der zum Verwerfen der Buchfuhrung fuhren kann.
