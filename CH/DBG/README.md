# Direkte Bundessteuer — Quellensteuer

Arbeitshilfen zum Satzformat der ESTV-Quellensteuertarife. Keine
Produktions-Tarifdateien (Repo ist öffentlich; ESTV sieht eine allgemeine
Publikation nicht vor).

| Dokument | Rolle |
|----------|--------|
| [quellensteuer-tarifformat.md](quellensteuer-tarifformat.md) | Recordarten, Feldlayout, Lookup, Rechtslage |
| [quellensteuer-aktualisierung.md](quellensteuer-aktualisierung.md) | Bezugskalender, SHA-256 statt Git |
| [qst-tarifcodes.csv](qst-tarifcodes.csv) / [qst-tarifcodes.json](qst-tarifcodes.json) | Codeliste A–Z, HE/ME/NO/SF, PEL/PPA/PSP/PLS, MED |
| [kantonskennzeichen.csv](kantonskennzeichen.csv) | 26 Kantone plus Flags `R`–`V` und `SF` |
| [tarife/2026/](tarife/2026/) | Manifest und Schweiz-ZIP 2026 (nach Download) |
