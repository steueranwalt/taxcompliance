  * Welche Tatigkeiten erbringen Sie im anderen Land?
  * Tatigkeit 

    * Vertrage verhandeln und Abschluss von Geschaften
    * Dienstleistungen

      * mit Kundenkontakt
      * ohne Kundenkontakt
    * Beratung / Unterricht
    * Einkauf von Waren
    * Verkauf von Waren
    * technische Unterstutzungsleistungen / Wartung / Service
    * Montagen / Bauarbeiten
    * Online-Dienste
    * Transporte
    * Programmierung
    * Fabrikation von Gutern / Herstellung / Verarbeitung / Veredelung

      * unternehmens(-gruppen-)intern
      * extern
  * Haufigkeit

    * standig
    * wiederkehrend regelmassig - wiederkehrend unregelmassig - x im Monat / Jahr
    * gelegentlich - x im Jahr
    * einmalig
  * Zeitraum
  * Wer macht das?

    * eigenes Personal im anderen Land
    * Personal aus dem Stammhaus
    * Fremdpersonal / externe Dienstleister

    * Geschaftseinrichtungen
