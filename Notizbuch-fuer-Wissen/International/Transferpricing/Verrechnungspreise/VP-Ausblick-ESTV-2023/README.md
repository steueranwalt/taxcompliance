Verrechnungspreis-Dokumentation

  * Als Teil der generellen Mitwirkungsobliegenheiten erwartet.
  * Solide Begrundung der wirtschaftlichen Substanz gruppeninterner Leistungsbeziehungen.
  * Bei Fehlen einer hinreichenden Dokumentation:

    * keine Rulings moglich.
    * Abschluss der Betriebsprufung basierend auf den verfugbaren Informationen (eventuell zum Nachteil des Steuerzahlers) 

Typische Streitfragen

Typische Diskussionen der ESTV beinhalten folgende gruppeninterne Leistungsbeziehungen:

  * Übertragungen von Immaterialgutern («IP»)
  * Finanzierungen
  * Dienstleistungen, insb. Management Dienstleistungen
  * Warenverkaufe

IP Bewertungen

Bewertungen von Immaterialgutern stellt ein Kernbereich der Tatigkeit dar.

  * ESTV grundsatzlich offen fur alle okonomisch begrundbare Bewertungsmethoden (DCF, Multi-Period-Excess-Earnings, Relief-from-Royalty, etc.)
  * Haufige Diskussionspunkte beinhalten: Kapitalisationszinssatz, Grossenpramie, wirtschaftliche Nutzungsdauer
  * Proaktive unterstutzende Analysen (keine Beschrankung auf eine einzige Bewerungsmethode)
  * Zumindest unilaterales Steuer-Ruling empfohlen

Gruppeninterne Dienstleistungen

  * Pragmatische Verfahren zur Kostenallokation werden anerkannt, sollten aber mit konkreten Beispielen erlautert werden.
  * Kostenaufschlagsmethode kann angefochten werden, wenn es sich nicht um «low-value-adding services» handelt.
  * Kantonale Steuerbehorden neigen dann dazu, das Gewinnaufteilungsverfahren anzuwenden.

Verluste bei Routine-Gesellschaften

  * Mit COVID bekamen Verluste fur Routine-Gesellschaften ein haufiges Thema.
  * Die ESTV beobachtet folgende Vorgehensweisen von Steuerzahlern:

    * Aufrechterhaltung der Routine-Entlohnung aber Justierung auf untere Grenze des Benchmarks
    * Herabsetzung auf break-even
    * Analysen zur Rechtfertigung von Verlusten der Routine-Gesellschaft
  * Explizite Berucksichtigung in den gruppeninternen Vertragen empfohlen
