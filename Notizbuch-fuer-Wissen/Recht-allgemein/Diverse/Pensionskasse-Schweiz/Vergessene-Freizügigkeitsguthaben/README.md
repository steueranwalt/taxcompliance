# Vergessene Freizügigkeitsguthaben 

Es kommt vor, dass die Versicherten vergessen, dass sie uber ein Freizugigkeitsguthaben verfugen. Das ist vor allem bei auslandischen Arbeitnehmenden der Fall, die die Schweiz endgultig verlassen. Die Broschure «Freizugigkeitsleistung: Vergessen Sie Ihre Vorsorgeguthaben nicht!» erklart den Versicherten, was eine Freizugigkeitsleistung ist, in welcher Situation sie sich darum kummern sollten und an wen sie sich wenden konnen, wenn sie glauben, uber ein vergessenes Guthaben zu verfugen.
