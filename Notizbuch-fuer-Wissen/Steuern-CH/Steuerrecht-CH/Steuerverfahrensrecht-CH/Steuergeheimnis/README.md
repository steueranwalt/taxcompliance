# Steuergeheimnis

Art. 110 DBG 

Geheimhaltungspflicht

  


1 Wer mit dem Vollzug dieses Gesetzes betraut ist oder dazu beigezogen wird, muss uber Tatsachen, die ihm in Ausubung seines Amtes bekannt werden, und uber die Ver­handlungen in den Behorden Stillschweigen bewahren und Dritten den Einblick in amtli­che Akten verweigern.

  


2 Eine Auskunft ist zulassig, soweit hiefur eine gesetzliche Grundlage im Bundes­recht gegeben ist.
