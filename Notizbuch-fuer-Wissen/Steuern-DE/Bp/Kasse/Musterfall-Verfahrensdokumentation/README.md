# Musterfall Verfahrensdokumentation

Ausgeschnitten aus: <https://www.dws-steuerberater-online.de/katalog/produkt/1503>

Die Zielsetzung einer Verfahrensdokumentation besteht insbesondere im Nachweis der Erfullung der in den GoBD definierten Ordnungsmaßigkeitsgrundsatze. Wollen Unternehmen in Betriebsprufungen keine Hinzuschatzungen riskieren, mussen sie eine Verfahrensdokumentation vorlegen konnen, die grundsatzlich aus einer allgemeinen Beschreibung, einer Anwender-, einer technischen System- und einer Betriebsdokumentation besteht.
